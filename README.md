# 🌟 مشروع مبصر (Mobser)

منصة ويب تفاعلية هادفة وخدمية، مصممة خصيصاً لمساعدة ذوي الإعاقة البصرية في بيئة العمل والأنشطة الرقمية من خلال التفاعل الصوتي.

---

### 🎯 فكرة المشروع وأهدافه:
* تم تطوير هذا المشروع إيماناً بأهمية التكنولوجيا في خدمة المجتمع وتسهيل اندماج ذوي الإعاقة البصرية في بيئة العمل الرقمية بكفاءة استقلالية تامة.
* يعتمد النظام على أوامر وتفاعل صوتي يقلل من حاجة الاعتماد الكلي على الشاشات البصرية التقليدية.

---

### 💻 التقنيات المستخدمة:
* **لغات البرمجة وتطوير الويب:** PHP, JavaScript, HTML, CSS
* **قواعد البيانات:** SQL Server / MySQL (لإدارة وحفظ البيانات بأمان)
* **بيئة التطوير والأدوات:** Visual Studio Code, XAMPP, Git & GitHub
